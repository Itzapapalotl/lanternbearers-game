# Lanternbearers

A family co-op dungeon crawl that runs in the browser. Light the braziers, push back the dark, and help each other up.

**Play:** https://itzapapalotl.github.io/lanternbearers-game/

Turn-based, for 1 to 4 players on one screen. There's nothing to install, and it saves in your browser. Claude's agent team built it, and Codex painted the art.

This repo holds only the built game. The source lives in a private repo.
