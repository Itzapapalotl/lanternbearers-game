# Lanternbearers

A family co-op dungeon crawl that runs in the browser. Light the braziers, push back the dark, and help each other up.

**Play:** https://itzapapalotl.github.io/lanternbearers-game/

**Game guide:** https://itzapapalotl.github.io/lanternbearers-game/guide.html

Turn-based, for 1 to 4 players on one screen. There's nothing to install, and it saves in your browser.

- **Chapter 1: The Deep Lanterns.** Relight the lanterns and face the Gloamwing.
- **Chapter 2: The Prism Deeps.** Bring the colors back and meet Pebblebelly.
- **Nibbet's Lantern Shop.** Spend your gold between rooms.

Claude's agent team built it, Codex painted the art, and Gemini wrote Chapter 2's story.

This repo holds only the built game. The source lives in a private repo.
